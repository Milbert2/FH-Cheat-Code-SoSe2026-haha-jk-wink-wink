Auf .NET Fiddle findest du den Basis-Code der Binary Search Tree Implementierung.

Implementiere die Funktion Successor (Nachfolger) und alle dazugehörigen Teilfunktionen aus dem binären Suchbaum.

Der Algorithmus für einen Knoten ist wie folgt:

  • Fall: Der Knoten hat ein rechtes Kind, dann ist der Nachfolger das Minimum des rechten Teilbaums
  • Fall: Der Knoten hat KEIN rechtes Kind, dann gehe solange den Baum (Parent) aufwärts, bis aus einem linken Teilbaum aufgestiegen wird. Dieser Knoten ist der Nachfolger

        {
            while (currentNode != null && searchKey.CompareTo(currentNode.Key) != 0)
            {
                if (searchKey.CompareTo(currentNode.Key) < 0)
                {
                    currentNode = currentNode.Left;
                }
                else
                {
                    currentNode = currentNode.Right;
                }
            }

            return currentNode;
